========================================================
            电控组资源站 · 自己改内容操作手册
========================================================

【总原则】你只需要动一个文件：data\resources.js
（只有"往站里放文件"的时候才需要碰 files\ 文件夹）

【本站怎么组织的】不再分"入门/进阶/毕业"这种阶段，
而是按【做什么】分成 6 个工作区，页面上每个工作区独立成一块：

    lang    编程语言
    mcu     单片机
    pcb     PCB
    vision  视觉
    tools   开发环境与工具
    algo    算法与仿真


-------------------------- 通用四步 --------------------------
1. 改：用记事本打开  D:\lab-hub\data\resources.js
2. 存：Ctrl+S 保存（编码选 UTF-8）
3. 看：双击桌面【电控组资源站(本地预览)】→ 按 F5 刷新看效果
4. 发：满意后双击  D:\lab-hub\发布更新.bat  → 1 分钟后网站更新


========================================================
一、加一个资源（最常用）
========================================================
复制下面这一块，粘到 resources.js 里 RESOURCES = [ ] 中间，
改成你的内容：

  {
    name: 'Dev-C++ 6.5 安装包',
    area: 'tools',
    size: '36 MB',
    desc: '轻量 C/C++ 编译器，装完就能写第一个程序',
    url: 'files/DevCpp65.exe'
  },

字段说明：
  name  资源名字（必填）
  area  放在哪个工作区：lang / mcu / pcb / vision / tools / algo
        （不写 area 资源不会显示在任何工作区里，一定要写）
  size  大小（不写就删掉这行）
  desc  说明（可选；不写就只显示名字和下载按钮，最简洁）
  url   下载地址（必填）

⚠️ url 两种写法：
  ① 站内文件：'files/文件名'   —— 文件必须真的放进 D:\lab-hub\files\ 里
  ② 外部链接：'https://...'     —— 网盘分享链接 / GitHub 下载直链

⚠️ 每条资源之间要有英文逗号 ,（最后一条后面不用加）


========================================================
二、给资源上锁（要钥匙才能下载）—— 可选
========================================================
在那一条资源里多加一行 lock，例如：

  {
    name: 'OpenMV 循迹例程合集',
    area: 'vision',
    size: '80 MB',
    desc: '🔒 钥匙藏在"编程语言"区的某份笔记里，自己找找看',
    url: 'files/openmv-demo.zip',
    lock: 'openmv'
  },

效果：这张卡不显示下载按钮，变成一个钥匙输入框；
      输对 openmv（或主密钥）才出现下载按钮。

钥匙怎么设计（几个套路）：
  · 藏在另一份开放资源的文件内容里（他必须先下载、认真看）
  · 藏在你的教程/笔记某一段话里
  · 让他交作业给你，你口头告诉他

不需要锁的资源，就不要写 lock 这行。


========================================================
三、改主密钥（万能钥匙，只有你知道）
========================================================
文件最顶部：

  masterKey: 'labmaster2026'

把 'labmaster2026' 换成你自己的词（建议长一点、跟学习有关的词）。
作用：输对主密钥能开【所有】锁。

⚠️ 提醒：网页是纯前端的，懂技术的能按 F12 看穿这把锁。
   所以别用锁保护隐私/贵重东西。


========================================================
四、改网站名字 / 标语 / 公告
========================================================
文件最顶部 SITE 里：

  name:   '电控组资源站'              ← 网页大标题
  sub:    '按工作区整理的电控学习资料'  ← 副标题
  notice: '🆕 各工作区正在陆续补充资料' ← 顶部小公告（不要就改成 ''）
  footer: '开启属于你的征途'           ← 页脚文字


========================================================
五、加 / 改 / 删工作区
========================================================
WORKSPACES 里加一行：

  { id: 'english', name: '英语资料', icon: '📘', desc: '专业英语与文献阅读' },

然后在资源里写  area: 'english'  就归到这个工作区了。

  id    英文代号，别重复（加资源时要用）
  name  显示名，随便起
  icon  一个 emoji
  desc  一句话简介，显示在工作区标题下面（不要就写 ''）

⚠️ 改已有工作区的 id 时，记得把资源里的 area 一起改，
   否则那条资源会「找不到归属」而不显示。


========================================================
六、往站里放大文件
========================================================
  · 几十 MB 以内（像 Dev-C++ 36MB）→ 直接丢进 D:\lab-hub\files\，
    资源里写 url: 'files/文件名'
  · 几百 MB ~ 2GB（Keil、CubeMX 等）→ 用 GitHub Releases：
    在网页版仓库 → Releases → Create a new release → 拖文件上传
    → 发布后复制文件链接，填到 url 里
  · 特别大的 → 网盘分享链接填 url（学弟点按钮跳网盘）


========================================================
七、改完怎么上线
========================================================
双击  D:\lab-hub\发布更新.bat
（等它跑完，约 1 分钟后刷新 https://xinghai-pu-2026.github.io/lab-hub/ 就是新的）


========================================================
八、常见错误自查（改坏了先看这里）
========================================================
✗ 用了中文引号 “钥匙”   → 必须用英文引号 '钥匙' 或 "钥匙"
✗ 少了逗号            → 每块 { } 之间、每个字段后面要有英文逗号 ,
✗ 文件路径写错         → url 写 files/名字，就必须有这个文件
✗ 忘写 area           → 资源不出现在任何工作区里（填 lang/mcu/pcb/vision/tools/algo）
✗ 保存成了 GBK 编码    → 记事本保存时选 UTF-8，中文才不乱码
✗ 改了没生效           → 先 F5 刷新预览；上线要双击发布 bat
