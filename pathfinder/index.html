🧭 寻路演示：BFS / A* / 安全代价

把地面想成方格纸，车只能走格子中心。点格子 = 放障碍。
BFS 像水一样均匀往外漫；A* 优先朝终点方向漫（查得少、更快）；
打开 💰安全代价 后，离障碍越近的格子"过路费"越贵，你会看到路线自动走到通道中间。

怎么玩：
1. 拖动鼠标在格子上画障碍（右键擦掉）
2. 「设起点」→点格子；「设终点」→点格子
3. 选 BFS / A*，点「开始搜索」看动画
4. 打开「💰安全代价」再搜一次，对比两条路线的差别
现在是"安全代价"模式：黄色越深 = 离障碍越近 = 走一格越贵（5 / 2 / 1.2 / 1 分）。 算法为了"总花费最小"，会自动选中间那条便宜的路 —— 也就是离墙最远的路。
